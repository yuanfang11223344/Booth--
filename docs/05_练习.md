# 05 自测练习

先在纸上推导，再用 `tb_trace.sv` 自选输入核对。只看最终十进制答案不够；目标是能解释**为什么**某一轮加、减或不操作。

1. **radix-2 手算**：取 W=4、`M=3,Q=-5`。写出 `Q` 的四位两补码，列出每轮 `Q[0],Q-1`，按先加减后整体算术右移更新 `{A,Q,Q-1}`。最终检查 8 位积。
2. **radix-4 分组**：取 W=5、`M=-7,Q=11`。写出三组重叠三位编码、各组数字及左移后的部分积。注意最高组的符号延拓。
3. **radix-8 权衡**：取 W=8、`M=-13,Q=23`。写出所有四位编码，找出是否产生 `±3M`。说明该例行数和 `3M` 硬件代价分别是什么。
4. **最小负数**：解释 W=8 时 `M=-128,Q=-1` 为什么要求在宽于 8 位的数据通路里做负倍数。运行 `+A=-128 +B=-1` 并检查结果 `128`。
5. **CSA 恒等式**：随便选三个 8 位向量 `a,b,c`，逐位验证 `a+b+c = (a^b^c) + (((a&b)|(a&c)|(b&c))<<1)`，按 8 位模加法比较。解释为什么压缩阶段不必全宽传播进位。
6. **接口设计**：假设上游每周期送入一对新输入。为什么迭代 radix-4 不能直接接受每周期一对？给它加一个输入 ready/valid 或者在并行乘法器外加流水线，并说明吞吐量与延迟的区别。
7. **综合结果解读**：查看 [第六章](06_综合与形式验证.md) 的 W=16 表。radix-4 CSA 的通用组合 cell 数为何没有低于线性链？列出至少两种可能的映射原因，并说明为什么不能把拓扑长度当成纳秒。
8. **证明范围**：W=8 的聚焦数据 SAT 固定了哪些控制输入？W=8/32 的独立控制归纳证明检查哪些输出？再说明第六章的“组合 miter + 时序记分板归纳”如何进一步证明 W=8 的乘积数值，以及为何这个结论仍限于指定初态和位宽。

命令示例：

```bash
mkdir -p build
iverilog -g2012 -s tb_trace -Ptb_trace.W=4 -o build/practice.vvp rtl/*.v tb/tb_trace.sv
vvp build/practice.vvp +A=3 +B=-5 +VCD=build/practice.vcd
python3 scripts/vcd_report.py build/practice.vcd
```

核对提示：第 1 题的完整积是 `-15=0xF1`；第 2 题是 `-77`；第 3 题是 `-299`。先完成编码和状态表，再看这些答案。
